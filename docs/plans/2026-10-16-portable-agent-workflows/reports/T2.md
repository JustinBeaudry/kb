## Selected interface

All curated commands (`get`, `get-node`, `recall`, `list-topics`, `map`) account for complete serialized stdout: JSON escaping, UTF-8 bytes, nonce, policy, chunks, decimal length prefix, and its newline. Default is 16,384 bytes. Precedence is explicit `--budget`, then valid `KB_RETRIEVAL_BUDGET`, then default. Map additionally retains valid `KB_MAP_BUDGET` as a legacy fallback below the common environment variable. Invalid legacy environment values continue to fall back, preserving the established map tests. Explicit invalid/nonpositive/nonintegral budgets fail with empty stdout and actionable stderr. A valid positive budget too small for a response also fails without stdout.

Small results retain the existing envelope and evidence fields. Truncation metadata is additive only when needed. The existing policy index signature can carry it, so no shared envelope type change is required.

`get` and `get-node` accept `--start-line <absolute-source-line>`. Omitted means the beginning of the page or selected section. A continuation stays inside the selected section, preserves the original node/heading metadata and exact source line ranges, and does not repeat or skip source lines. Individual lines are not split, preventing partial Unicode or dishonest line provenance. When the first requested line cannot fit, fail with its absolute line number and an explicit `--budget` remedy; never issue a continuation that repeats the same failed request.

`recall` and `list-topics` accept `--offset <zero-based-result-offset>`. Recall continues beyond the old silent twenty-result cap. Stable traversal/result ordering is required. Large result sets expose `policy.truncated: true` and:

```json
{
  "continuation": {
    "command": "get",
    "args": ["guide", "--start-line", "14", "--budget", "1200", "-p", "/resolved/vault"]
  }
}
```

Continuation arguments retain the explicit byte budget and resolved vault path so replay does not depend on the caller's directory or environment. Tests execute the returned argument vector through the real CLI. Offset continuations use the same structure with `--offset`.

Map keeps its existing three degradation tiers, narrower-query hints, and raise-budget recovery. No map pagination or `--tier` framework is introduced. Its successful result must respect the full wire limit in every path, including empty/no-result envelopes and a zero-chunk truncated envelope. The existing 420-byte truncation response remains valid when its envelope fits.

Optional get-node neighbors and wikilink previews share the primary evidence budget. Primary evidence is fitted first. Omitted optional evidence sets truncation and provides explicit get-node recovery suggestions; fitting the primary chunk must not falsely imply that all requested evidence was returned.

Startup defaults to lazy when configuration is absent, malformed, or unrecognized. Valid explicit eager configuration/environment continues to include curated `context.md` then `index.md`, but never session manifests or generated session summaries. Existing vault configuration is not rewritten.
