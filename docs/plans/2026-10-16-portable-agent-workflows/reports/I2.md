# I2: Bounded curated retrieval and optional startup context

Status: implementation complete in owned files; targeted checks pass. Ready for root C2 and final review. No commits made.

## Implemented behavior

- Added `src/lib/retrieval.ts` for strict explicit budget parsing, environment fallback, complete-wire byte measurement, whole-line page fitting, whole-result pagination, and replayable continuation arguments. Helpers return errors as values; commands own stderr/exit behavior.
- `get` and `get-node` now accept `--budget` and absolute `--start-line`. Partial evidence retains exact source lines and existing node/heading metadata. Continuations retain the requested budget and resolved absolute vault path through `-p`. Invalid ranges fail explicitly. A first requested line that cannot fit fails with empty stdout and a concrete larger-budget retry.
- `recall` and `list-topics` now accept `--budget` and zero-based `--offset`. Recall results use deterministic path/line ordering and no longer silently stop after twenty matches. Whole-result pagination keeps an executable continuation; an indivisible result that cannot fit gets an explicit larger-budget remedy.
- `map` retains its existing tiers and hints, including the 420-byte zero-chunk truncation response. It uses the common strict explicit budget parser and checks the final wire in every path, including no results. Valid `KB_MAP_BUDGET` remains a legacy fallback below `KB_RETRIEVAL_BUDGET`; invalid environment values keep falling back.
- `get-node` budgets the primary chunk before optional neighbors/previews. Optional chunks are retained in request order when they fit. `policy.omitted_nodes` identifies omitted or partial nodes, with a get-node recovery suggestion including the resolved vault path. `nav_trace` lists only returned navigation targets. Wikilink previews now end at exact source-line boundaries and mark omitted tails.
- Absent, malformed, or invalid injection configuration defaults to lazy. Valid explicit eager mode still fits curated `context.md` then `index.md` within its existing startup budget, but never reads/injects raw session manifest bodies or generated summary bodies. The optional one-line unprocessed-session count remains supported. Existing configuration files are not rewritten.

Small retrieval responses keep existing text, line ranges, curation/node metadata, and policies when no truncation applies. The existing open policy shape carries additive continuation/omission metadata; `src/lib/envelope.ts` is unchanged. Map gets no pagination or new tier flag.

## Review notes and limits

- Source reads and response shaping do not write curated evidence. Existing operational access logs and map cache writes remain allowed.
- Continuations represent source offsets, not immutable snapshots. They assume the vault is unchanged between calls. Invalid later line/result offsets fail rather than fabricating evidence; snapshot tokens are outside this increment.
- `recall` paginates whole context snippets. A snippet larger than the requested budget returns an actionable budget error instead of splitting a match or silently skipping it.
- Omitted-node metadata and its recovery hint consume the same wire budget as primary evidence. A budget too small even for the necessary primary evidence plus metadata fails without stdout.
- Full-suite, deterministic evaluation, and final-review results belong to root C2/R1/C3 and are not claimed here.
