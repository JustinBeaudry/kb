# Refine the vault

Read the [KB entry point](../kb/SKILL.md), then the
[maintenance guide](../kb/references/maintenance.md).

Establish the findings and apply changes within the user's authorized scope.
Preserve provenance, inspect the resulting links and report only measured
improvements. A lint or question request alone does not authorize edits.
